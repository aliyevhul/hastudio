# freelance

Personal workspace for my portfolio and for websites I build for money.
Separate from HRMS/AIMP work on purpose.

## Layout

| Folder | What goes in it |
|--------|-----------------|
| `portfolio/` | My own site + case studies. This is the shop window. |
| `sites/` | One folder per client/paid site. `sites/<client-slug>/` |
| `clients/` | Per-client notes: scope, prices, credentials pointers (never secrets), handover docs |
| `assets/` | Reusable components, templates, snippets, images, logos |
| `notes/` | Learning notes, pricing research, competitor teardowns |
| `IDEAS.md` | The idea log — Inbox → Shortlist → Shipped |

## Rules I keep

- No secrets in this repo. API keys, passwords, client credentials stay out. Ever.
- Every paid site gets a `sites/<slug>/SCOPE.md` before a single line of code.
- Anything built twice gets extracted into `assets/`.
- Nothing is "done" until it's live and listed in IDEAS.md → Done / Shipped.
